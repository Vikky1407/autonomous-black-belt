What format does my file need?
  • A header row, then one row per case (an invoice, a ticket, a batch)
  • One numeric output to improve: cycle time, weight, accuracy
  • The inputs you want tested: team, channel, shift, machine
  • A date column (YYYY-MM-DD) for the control chart
  • At least 20 rows; ID columns are ignored automatically
